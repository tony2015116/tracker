# 每日打卡记录 · 安装版

把这几个文件放到一个网址上，用 Chrome 或 Edge「安装为应用」。安装后，数据文件夹只需授权一次，以后打开不会再询问。

**数据不会上传。** 网址上只放页面代码，打卡数据只写在你自己电脑的数据文件夹里。

## 用 GitHub Pages 发布（免费，约 5 分钟）

1. 登录 GitHub，新建一个仓库，比如叫 `tracker`。
   - 免费账号的 GitHub Pages 需要公开仓库。
   - 公开的只是页面代码，你的打卡数据不在仓库里。
2. 在仓库页面点 **Add file → Upload files**，把这几个文件拖进去，然后点 **Commit changes**：
   - `index.html`
   - `manifest.webmanifest`
   - `sw.js`
   - `icon-192.png`
   - `icon-512.png`
3. 进入仓库的 **Settings → Pages**，在 *Build and deployment* 里选 **Deploy from a branch**，分支选 `main`，目录选 `/ (root)`，然后保存。
4. 等 1～2 分钟，页面顶部会显示网址，形如 `https://你的用户名.github.io/tracker/`。
5. 用 Chrome 或 Edge 打开这个网址，然后安装：
   - 点页面标题旁的 **「📲 安装为应用」**，
   - 或点地址栏右侧的安装图标。
6. 从桌面或开始菜单打开「每日打卡记录」，点「选择数据文件夹」，选你原来的那个文件夹，原有数据会自动读进来。

## 之后

- 只需第一次授权文件夹访问。以后打开会自动连接，页面顶部的横条会显示绿色。
- 断网也能打开和打卡。导出 Excel 第一次需要联网，之后会缓存下来。
- 以后更新页面时，用新文件替换仓库里的 `index.html` 即可。已安装的应用会在下次打开时自动更新，有时需要打开两次才生效。

## 常见问题

**安装按钮没出现？**
- 确认是用 Chrome 或 Edge 打开的 `https://` 网址，不是双击本地文件打开的。
- 也可以从浏览器菜单安装：
  - Chrome：菜单 → 投放、保存和分享 → 将网页安装为应用。
  - Edge：菜单 → 应用 → 将此站点作为应用安装。

**安装后还是每次都问？**
打开 `chrome://settings/content/filesystem`，看看这个网址有没有被设成「每次询问」。另外，如果开启了「关闭所有窗口时清除 Cookie 及网站数据」，浏览器会忘掉文件夹，需要把这个网址加入例外。
